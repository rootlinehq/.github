# Café asset sources

The example reuses the cappuccino and croissant photography shown on [Rootline Cafe](https://rootline.cafe), supplied as company demo assets:

- [Cappuccino](https://rootline.cafe/images/cappuccino.jpg)
- [Croissant](https://rootline.cafe/images/croissant.jpg)

`geist-latin.woff2` is the Geist Sans Latin variable font served by that site. Its [SIL Open Font License](./OFL.txt) is included; see the [Geist project](https://github.com/vercel/geist-font). The font is unchanged.

These files are served locally so the preview makes no requests to Rootline Cafe, Rootline's API, a font CDN, or the SDK CDN. The Rootline logo and payment icons keep their existing sources. Company artwork remains subject to the publication review in the ignored publishing guide.
